# 2en Apps Management System

## About The Project

The 2en Apps Management System is a web-based system designed to manage HR activities and simplify daily employee management processes.

## Technologies Used

- **Frontend:** Vue.js
- **Backend:** Laravel
- **Database:** MySQL
- **API:** REST API

## System Modules

1. Dashboard, staff profile and details
2. Attendance Management
3. Leave Management
4. Claims Management
